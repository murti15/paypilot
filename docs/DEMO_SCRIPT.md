# PayPilot — Demo Video Script

**Target duration:** 3–4 minutes.

Record the demonstration only after the corresponding features work. Do not present planned functionality as completed functionality.

## 1. Introduction — 15 seconds
Introduce PayPilot as a salary management and compensation analytics application designed for an organization with 10,000 employees across multiple countries.

## 2. Dashboard — 30 seconds
Show the employee count and compensation summaries. Explain how analytics are grouped by currency to avoid misleading cross-currency totals.

## 3. Employee Directory — 40 seconds
Demonstrate employee search, department and country filters, sorting, pagination, and opening an employee profile.

## 4. Salary Update — 40 seconds
Using an authorized HR Manager account, update a synthetic employee's salary. Show validation feedback and the saved salary-change history.

## 5. Viewer Permissions — 30 seconds
Sign in as a Viewer. Demonstrate that individual salary values are not exposed and salary updates are rejected by the backend.

## 6. Engineering Quality — 30 seconds
Show the repository structure, automated test results, CI checks, and important architecture decisions. Mention only checks that were actually run.

## 7. Conclusion — 15 seconds
Summarize the core features and explain the main exclusions, such as payroll execution and live currency conversion.

## Recording Checklist
- [ ] Use synthetic employee data only.
- [ ] Verify all demonstrated flows before recording.
- [ ] Do not show passwords, tokens, or environment secrets.
- [ ] Show the actual deployed application.
- [ ] Ensure the final video link is accessible to the reviewer.
